# Конфигуратор здания (UE 5.8)

Откройте `Apartments.uproject` в Unreal Engine 5.8 и разрешите редактору собрать C++ модуль. На Windows для сборки нужен установленный C++ toolchain Visual Studio 2022.

Стартовая карта — `Content/Levels/L_Main_P.umap`. `BP_GameMode` назначает `BP_CameraPawn`. Конфигурация здания находится в `Source/Data/config.json` и загружается автоматически при запуске через `UDataSubsystem`.

В текущем состоянии реализованы загрузка JSON и переключение ракурсов камеры. UI и взаимодействие с квартирами в сцене ещё в работе.

Импортированный пакет `Content/FantasyInterior01` не включён: текущая карта и проектные Blueprint на него не ссылаются. Папки сборки и кеши Unreal Engine также не нужны для открытия проекта — редактор создаст их заново.
