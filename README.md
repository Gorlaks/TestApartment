Unreal Engine 5.8. Apartments.uproject, уровень L_Main_P. Данные json лежат в Source/Data/data.json и загружаются при запуске

## Архитектура

- UDataSubsystem (GameInstanceSubsystem) хранит данные, чтобы камера, сцена и интерфейс брали их из одного места. Чтение файла и разбор JSON идут в фоновом потоке; результат передаётся в игровой поток. При ошибке уже загруженные данные не заменяются
- FJsonParser отдельно проверяет структуру и обязательные поля JSON. Ну и собирает данные
- ACameraPawn отвечает за общий вид, переход к этажу и квартире, вращение вокруг здания и кнопки "Назад" и "Общий". Tick включается только на время плавного перелёта
- UUnitComponent связывает экземпляр BP_Unit с квартирой по UnitId, обрабатывает клик и меняет материалы выбранных статик мешей
- UUnitSceneSubsystem (WorldSubsystem) хранит текущий выбор и состояние фильтра проданных квартир. Когда они меняются, подсистема обновляет компоненты квартир на уровне.
- AMainHUD создаёт интерфейс, а UConfiguratorWidget строит кнопки этажей и квартир из загруженных данных и показывает карточку квартиры

Внешний вид, меши квартиры, материалы, настройки камеры, управление мышью и разметка UMG настраиваются в Blueprint. C++ отвечает за данные и поведение
